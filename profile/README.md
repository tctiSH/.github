# tctiSH

tctiSH is a lightweight and high-performance Linux virtual machine that runs on iOS and iPadOS, inspired by [iSH](https://github.com/ish-app/ish) and [UTM](https://github.com/utmapp/utm). It is built on top of our [fork](https://github.com/tctiSH/qemu) of QEMU which incorporates the TCTI pseudo-JIT to run arbitrary code with reasonable performance even without a JIT (though it can also JIT on-demand as well). 

This organisation contains the primary repository for [tctiSH](https://github.com/tctiSH/tctiSH), as well as the forks that support its development. We do not recommend use of any of these forks outside tctiSH.
